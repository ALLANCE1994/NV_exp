# 软件延迟实现说明

## 概述

为了解决myDAQ使用内部时钟从t=0开始采样，而PB的DAQ脉冲窗口在特定时间点开始的问题，我们实现了软件延迟机制，确保采样点正确对齐到PB的DAQ脉冲窗口内。

## 问题背景

### myDAQ采样机制
- myDAQ使用内部时钟，从t=0开始采样
- 采样点按照固定间隔分布：t=0, t=sample_interval, t=2*sample_interval, ...
- 无法直接设置采样起始时间

### PB脉冲序列
- PB的DAQ脉冲窗口在特定时间点开始
- ESR实验：窗口在t_duration - t_readoutBuffer时刻开始
- Rabi实验：窗口在AOM_readout + t_readoutDelay时刻开始

### 问题
- myDAQ的采样点可能落在PB的DAQ脉冲窗口外
- 导致采集不到有效数据

## 解决方案：软件延迟

### 实现原理

1. **计算理想采样时刻**
   - 确定PB的DAQ脉冲窗口中心
   - ESR: sample_time_1 = t_halfCycle_ns - t_readoutBuffer + t_readout/2
   - Rabi: sample_time_1 = DAQ_start1 + t_readout/2

2. **计算调整系数**
   - 找到最接近理想采样时刻的采样点
   - k = round(sample_time_1 / sample_interval)
   - adjusted_sample_time_1 = k * sample_interval

3. **计算软件延迟**
   - software_delay_sec = adjusted_sample_time_1 / 1e9
   - 在读取DAQ数据前应用此延迟

### 代码实现

#### ESR实验 (configureDAQbyTime)
```python
# 计算理想的采样时刻（窗口中心）
sample_time_1 = pb_pulse_start_1 + t_readout / 2

# 计算调整系数
k = round(sample_time_1 / actual_sample_interval)
adjusted_sample_time_1 = k * actual_sample_interval

# 计算软件延迟时间（秒）
software_delay_sec = adjusted_sample_time_1 / 1e9

# 返回DAQ任务、实际样本数和软件延迟时间
return readTask, actualTotalSamples, software_delay_sec
```

#### Rabi实验 (configureDAQforRabi)
```python
# 计算理想的采样时刻（窗口中心）
sample_time_1 = pb_pulse_start_1 + t_readout / 2

# 计算调整系数
k = round(sample_time_1 / sample_interval_ns)
adjusted_sample_time_1 = k * sample_interval_ns

# 计算软件延迟时间（秒）
software_delay_sec = adjusted_sample_time_1 / 1e9

# 返回DAQ任务和软件延迟时间
return readTask, software_delay_sec
```

#### 主控制流程 (mainControl_MyDAQ)
```python
# 配置DAQ并获取软件延迟
result = DAQctl.configureDAQbyTime(acquisitionTimePerSample_ns, expCfg.Nsamples)
DAQtask, actualTotalSamples, software_delay = result

# 在读取DAQ数据前应用软件延迟
if software_delay > 0:
    print(f"应用软件延迟: {software_delay:.6f} 秒")
    time.sleep(software_delay)

# 读取DAQ数据
cts = DAQctl.readDAQ(DAQtask, actualTotalSamples, expCfg.DAQtimeout)
```

## 优势

1. **精确对齐**：确保采样点落在PB的DAQ脉冲窗口内
2. **简单实现**：无需修改硬件配置，纯软件实现
3. **自动计算**：根据实验参数自动计算最优延迟时间
4. **验证机制**：提供采样点对齐验证，便于调试

## 注意事项

1. **采样率限制**：如果计算出的采样率超过200kHz，会自动调整为200kHz
2. **延迟精度**：软件延迟的精度受限于Python的time.sleep()函数（通常为毫秒级）
3. **时序验证**：运行实验时，务必查看日志输出中的对齐验证结果

## 使用方法

1. 配置实验参数（ESRconfig.py或Rabiconfig.py）
2. 运行实验（mainControl_MyDAQ.py）
3. 查看日志输出中的"验证采样点与PB脉冲窗口的对齐"部分
4. 确认所有采样点的"在窗口内"都为True
5. 如果为False，检查实验参数是否合理

## 总结

通过软件延迟机制，我们成功解决了myDAQ内部时钟与PB脉冲序列的时序不匹配问题，确保采样点正确对齐到PB的DAQ脉冲窗口内，从而采集到有效的信号和背景数据。
